# HR Transfer Workflow

## Member Transfer Flow

```
Transfer request submitted
        ↓
Willen Committee notified
        ↓
Committee approves / rejects
        ↓
On approval: org chart updated on next scheduled run
        ↓
Member and Department Manager notified
```

## Org Chart Updates

Org chart updates run on a **schedule** (daily or weekly, configurable). Admins can trigger an immediate manual update if needed.

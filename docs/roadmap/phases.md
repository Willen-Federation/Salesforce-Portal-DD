# Development Phases

## Overview

| Phase | Focus | Status |
|---|---|---|
| 🔴 **MVP** | Core operations — membership, HR, applications, payments, notifications, licenses | Planning |
| 🟡 **Phase 2** | Member-facing features — events, resources, departments, help center, ordering | TBD |
| 🟢 **Phase 3** | Advanced features — form builder, native apps, international expansion | TBD |

## Development Notes

- **Solo developer** project — no fixed deadline
- Quality and correctness prioritised over speed
- Each phase reviewed and adjusted based on member feedback
- Salesforce org already exists

## Phase Details

### 🔴 MVP

| Module | Key Deliverables |
|---|---|
| Membership Management | Member profiles, editing, sync foundations |
| HR Management | Org structure, dept setup, org tree, member transfers |
| Application Forms | New member form, fee collection, 5-outcome approval |
| License Management | Request form, Committee routing, tracking |
| Notification Service | Email + Slack, mail merge, Excel import |
| Payment Integration | Pay.jp, Omise, GMO Aozora API setup |
| Annual Membership Fee | Recurring yearly subscription |
| Workflow Engine | Core approval workflows |

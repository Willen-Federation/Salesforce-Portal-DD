# MVP Scope

## In Scope

1. Membership Management
2. HR Management (org tree, departments, transfers)
3. Application Forms + 5-outcome workflow
4. License Management (request/tracking)
5. Notification Service (email + Slack + mail merge)
6. Payment Integration (Pay.jp + Omise + GMO Aozora)
7. Annual Membership Fee (subscription)
8. Workflow Engine

## Out of Scope for MVP

- Events and QR tickets
- Resource sharing
- Department pages (beyond basic org tree)
- Help center / cases
- Ordering and donations (beyond membership fee)
- Stripe (international)
- Form builder
- Native mobile apps

## Success Criteria

- [ ] New member can apply and pay online
- [ ] Committee can approve/reject in Salesforce
- [ ] Members can edit their profiles
- [ ] Org tree is visible and accurate
- [ ] License requests tracked and routed to Committee
- [ ] Admin can send personalised notifications
- [ ] Annual membership fee auto-collected
- [ ] Bank transfers confirmed via GMO Aozora webhook

# Resource Sharing

**Phase:** 🟡 Phase 2

## Overview

Centralised repository for all organisational resources, accessible to members based on department and access level.

## Resource Types

| Type | Examples |
|---|---|
| Documents | Guidelines, manuals, policies, meeting minutes |
| Templates | Excel, Word, PowerPoint templates |
| Tools & Links | Links to internal/external tools used by the org |
| Knowledge Base | How-to articles, FAQs, tutorials |
| Files | ZIP archives, PDFs, images |

## Features

| Feature | Detail |
|---|---|
| Organisation | By department AND by tag/category |
| Upload Access | Any member can upload |
| Search | Full-text search across all resources |
| Version History | Document versioning — full history maintained |
| Access Control | Org-wide or restricted to specific departments |

## Access Levels

| Level | Who Can See |
|---|---|
| **Org-wide** | All logged-in Willen members |
| **Department-restricted** | Only members of that specific department |
| **Admin only** | Committee and admins only |

## Search & Discovery

- Full-text search across titles, descriptions, and content
- Filter by department, tag, file type, date
- Sort by most recent, most viewed, or alphabetical
- Tag-based categorisation for cross-department resources

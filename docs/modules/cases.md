# Case Management & Help Center

**Phase:** 🟡 Phase 2

## Overview

Private member support cases routed to Willen Committee, with a self-service FAQ and knowledge base to reduce case volume.

## Features

| Feature | Detail |
|---|---|
| Case Types | Technical support, Billing, General enquiry, HR |
| Default Routing | All cases → Willen Committee |
| Privacy | Private — submitter + Committee/admins only |
| Self-service FAQ | Knowledge base accessible before submitting |
| SLA Tracking | Response time targets tracked per case type |
| File Attachments | Screenshots, documents attachable on submission |
| Status Tracking | Open, In Progress, Resolved, Closed |

!!! important "Cases are private"
    Members cannot see each other's cases. Each case is visible only to the submitter and Willen Committee/admins.

## Case Flow

```
Member submits case (with optional attachments)
        ↓
Case created in Salesforce
        ↓
Willen Committee notified
        ↓
Committee assigns and works case
        ↓
Member updated on progress
        ↓
Case resolved → member notified
```

## Self-Service FAQ

Before submitting a case, members are directed to the knowledge base:

- Searchable FAQ articles
- Step-by-step guides
- Common issue resolutions
- Linked to relevant portal features

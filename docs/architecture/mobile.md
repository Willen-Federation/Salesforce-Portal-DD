# Mobile & Web

## Platform Support

| Platform | Type | Status |
|---|---|---|
| Web (desktop) | Responsive web | 🔴 MVP |
| Web (mobile) | Responsive web (mobile-optimised) | 🔴 MVP |
| iOS | Native app | 🟢 Phase 3 |
| Android | Native app | 🟢 Phase 3 |

## Languages

All interfaces are **bilingual**:

- **Japanese (日本語)** — primary language for domestic members
- **English** — for international members, donors, and Willen Federation pages

## Responsive Web (MVP)

The Experience Cloud portal will be fully responsive from MVP, covering:

- Desktop browsers
- Mobile browsers (iOS Safari, Android Chrome)
- Tablet browsers

## Native Apps (Phase 3)

Native iOS and Android apps will be developed in Phase 3, likely using:

- Salesforce Mobile SDK, or
- React Native / Flutter with Salesforce API integration

Native apps will include push notification support for improved member engagement.
